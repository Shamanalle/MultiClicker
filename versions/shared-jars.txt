# Minecraft versions released as one jar: one group per line, "<loader>: <versions, oldest first>".
#
# The jar is built for the newest version of the group and declares the whole range in its metadata. Every
# version is still built and tested on its own, and the release only goes ahead when the jars built for the
# versions of a group hold the same code (.github/scripts/release_groups.py), so each reference in the shared
# jar was resolved against every version it is released for.
#
