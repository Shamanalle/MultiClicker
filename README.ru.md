# MultiClicker

**Автокликер для Fabric с помощниками для AFK-ферм, копания и рыбалки.**

- **Играет как рука на мышке.** Мод нажимает обычные клавиши игры, поэтому перезарядка атаки,
  ломание блоков и синхронизация с сервером работают так же, как при ручной игре. Клавиши, которые
  вы держите сами, мод никогда не отпускает.
- **Помощники не мешают друг другу.** Авто-еда, авто-инструмент, вторая рука и кликер пользуются
  хотбаром по очереди. Никто не меняет предмет в руке у другого, и каждый возвращает ваш слот.
- **Проверен в настоящей игре.** На каждый пуш CI запускает Minecraft и проигрывает 14 сценариев
  в живом мире: бой, еду, копание, рыбалку, аварийную остановку.

## Возможности

| | Модуль | Что делает |
|:--|:--|:--|
| **Кликер** | Автокликер | Отдельные каналы атаки, использования и прыжка. Каждый умеет кликать или держать клавишу, у каждого свой интервал, время удержания и случайная задержка. Умеет ждать полной зарядки оружия, добивать оружием с «Добычей», фиксировать камеру, останавливаться по лимиту атак или времени и работать, когда окно в фоне. |
| **Бой** | Фильтр целей | Игроки, враждебные, нейтральные и мирные мобы, прочие сущности. Можно не трогать детёнышей, мобов с биркой, питомцев и невидимых. Стойки для брони по умолчанию не бьются. |
| **Выживание** | Безопасность | Останавливает мод или выходит с сервера, когда мало здоровья, при любом уроне или если рядом игрок. |
| | Вторая рука | Держит во второй руке самое нужное, в таком порядке: тотем при малом здоровье, еда при голоде, факел к кирке, иначе щит. |
| | Авто-еда | Ест лучшую безопасную еду из хотбара и возвращает слот. Пропускает вредную и золотую еду, никогда не открывает сундук перед вами. |
| **Автоматизация** | Авто-рыбалка | Подсекает при поклёвке и снова забрасывает. Перезабрасывает при долгом ожидании, бережёт удочку, есть лимит улова. |
| | Анти-АФК | Прыжок, присед, взмах рукой, поворот камеры или шаг через случайные интервалы. |
| | Авто-ходьба | Идёт вперёд. Умеет бежать и перепрыгивать препятствия. |
| | Очистка инвентаря | Выбрасывает мусор из списка и не трогает хотбар. |
| **Копание** | Правила копания | Белый или чёрный список блоков. Может останавливаться при полном инвентаре и беречь инструмент от поломки. |
| | Авто-инструмент | Берёт из хотбара самый быстрый инструмент для блока (с учётом «Эффективности»), потом возвращает слот. |
| **Визуал** | HUD · Подсветка цели | Панель состояния: каналы, клики в секунду, атаки, убийства, время, пинг, TPS и FPS. Следующая цель подсвечивается контуром, заливкой или свечением. |

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft **1.21.8**.
2. Положите в папку `mods` [Fabric API](https://modrinth.com/mod/fabric-api) и
   [`MultiClicker-fabric-<версия>.jar`](https://github.com/Shamanalle/MultiClicker/releases/latest).
3. По желанию поставьте [Mod Menu](https://modrinth.com/mod/modmenu): он добавляет кнопку настроек в списке модов.

## Управление

| Клавиша | Действие |
|:--:|:--|
| <kbd>I</kbd> | Включить / выключить мод |
| <kbd>O</kbd> | Открыть настройки |

Клавиши меняются в *Настройки → Управление → Назначение клавиш → MultiClicker*.

В меню:
- Чтобы найти настройку, просто начните печатать.
- Правый клик по настройке сбрасывает её.
- Колесо мыши или стрелки точно подстраивают ползунки.

## Быстрый старт

- **Моб-ферма.** Выберите *Профили → Моб-ферма*, наведитесь на место спавна и нажмите <kbd>I</kbd>.
  Каждый удар идёт на полной зарядке, питомцы и мобы с биркой не трогаются.
- **«Добыча».** Держите меч с «Добычей» в хотбаре и включите *Добивать Добычей*. Перед смертельным
  ударом мод берёт этот меч, ждёт его зарядки, бьёт и возвращает прежний слот.
- **AFK-копание.** Выберите *Профили → Копание*. Кликер держит атаку, авто-инструмент берёт кирку,
  а при полном инвентаре кликер останавливается.
- **Рыбалка.** Выберите *Профили → Рыбалка*, возьмите удочку и нажмите <kbd>I</kbd>.

Пока открыт любой экран (инвентарь, чат или меню), кликер стоит на паузе и отпускает клавиши.

> На многих серверах автокликеры запрещены. Проверьте правила, прежде чем играть с модом по сети.

## Настройки

Настройки хранятся в `config/multiclicker.json`, профили в `config/multiclicker/profiles/`.

## Сборка

Нужен JDK 21.

```bash
./gradlew build                       # → fabric/build/libs/MultiClicker-fabric-<версия>.jar
./gradlew :fabric:runClientGameTest   # запускает игру и проигрывает все сценарии
```

- `common/` содержит сам мод: модули, настройки, меню и конфиг.
- `fabric/` содержит точку входа Fabric.
- `fabric/src/gametest/` содержит игровые тесты. В релизный jar они не попадают.
