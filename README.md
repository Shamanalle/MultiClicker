# Multi Clicker

A modern, highly configurable auto clicker mod for Minecraft (Fabric/NeoForge).

## Features

- **Auto click (hold & spam)** for Right and Left click
- **Lag-proof Entity Protection**: Prevents accidental entity destruction (e.g. Armor Stands) even during severe server lag.
- **Configurable timeout**: Adjust protection settings to your needs.
- **Bot/Macro functionality**: Randomization, Target Delay, Rotation Protection.

## How to use

- Open GUI with `O` (default key) to enable and edit settings.
- Use `I` (default key) to toggle the auto clicker.

### Modes

- **Click**: Fast press+release.
- **Hold**: Holds button for N ticks. For shields/bows/eating.

### Stats

- **DPS**: Real-time damage per second (15s sliding window).
- **KPM**: Kills per minute.
- **Ping**: Current server latency.

## Use on servers

Use at your own risk on public servers. Ensure you comply with server rules.
